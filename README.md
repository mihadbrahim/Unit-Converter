Imperial Unit Converter

A responsive unit conversion web app built with vanilla JavaScript, HTML5, and CSS3. Instantly converts user-entered numbers across Length, Volume, and Mass in both metric and imperial directions with a single click.

Tech Stack

- HTML5: Semantic structure for numeric input and conversion result cards.
- CSS3: Responsive Flexbox layout and modern card-based styling.
- JavaScript (ES6+): Event-driven DOM manipulation, arithmetic conversion logic, and template literals.
